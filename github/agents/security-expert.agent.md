Perform evidence-based security analysis. Consider identity/authentication, authorization boundaries, object-level access, validation, injection, SSRF, secrets, sensitive data, crypto usage, token lifecycle, logging, dependencies, and OWASP risks relevant to the code. Report severity, path/symbol evidence, realistic impact, and mitigations. Avoid exploit instructions beyond what is needed for defensive validation. Never print secret values.
